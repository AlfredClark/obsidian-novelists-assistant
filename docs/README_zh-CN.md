# Novelists Assistant

[English](../README.md) | **简体中文**

![Novelists Assistant 预览图](images/preview.png)

使用各种写作工具增强你的小说写作体验，使复杂的故事情节井然有序。

## 功能

### 默认目录结构

- 一键创建「设定」与「正文」文件夹（英文界面为 Lore/Novel）并自动指向设置
- 启动时自动探测已存在的默认文件夹并补齐指向

### 正文排版

- 为正文目录内的文件提供首行缩进与行高，源码视图与阅读视图均支持
- 阅读视图拥有独立开关与参数；软换行渲染为独立缩进的行

### 网格线

- 在源码视图中为正文文件每行下方绘制网格虚线，如稿纸一般
- 虚线长度、间隔、厚度、不透明度均可配置

### 快捷菜单

- **新建章节**（文件菜单）：在正文目录创建下一章节，编号自动递增，支持阿拉伯数字、中文小写、中文大写三种样式，并在当前标签页打开
- **添加到设定**（编辑菜单）：将选中文本创建为所选设定子文件夹中的设定笔记
- **同步设定链接** / **清空设定链接**（编辑菜单）：一键为当前笔记中的设定名称包裹或解除 wiki 链接
- **章节转换**（设置页）：在编号格式之间批量重命名既有章节

### 字数统计（文件列表）

- 每个文件旁显示字数——计数前剔除全部 Markdown 标识，汉字逐字计 1，英文与数字按词计 1
- 文件夹统计：设定文件夹显示设定总数与组数，正文文件夹显示总字数与章节数，设定子文件夹显示设定数
- 所有单位均可配置，也可留空隐藏

## 安装

### 社区插件市场（推荐）

1. 打开 Obsidian **设置 → 第三方插件**
2. 关闭**安全模式**
3. 点击**浏览**，搜索「Novelists Assistant」并安装

### 手动安装

1. 从[最新发布](https://github.com/AlfredClark/obsidian-novelists-assistant/releases)下载 `novelists-assistant.zip` 并解压，或直接下载 `main.js`、`manifest.json`、`styles.css`
2. 放入 `Vault/.obsidian/plugins/novelists-assistant/`

## 设置

所有功能在设置页分组呈现，可独立开关。界面语言跟随 Obsidian（英文/简体中文/繁体中文），也可手动指定。

## 兼容性

- Obsidian 1.13.1 及以上
- 仅桌面端
